# AHP Operations Dashboard

Atlanta Houseplants operations and project management dashboard.

## Features

- **Active Workflows**: Track multi-step projects with progress bars
- **The Hook**: Immediate action items from memory/the-hook.md
- **Calendar**: Next 7 days view of installs, services, meetings
- **Activity Feed**: Recent actions and results

## Development

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
# Static export to /dist
```

## Data Sources

- Workflows: `memory/workflows.md`
- The Hook: `memory/the-hook.md`
- Activity: `memory/activity-feed.md`
